# iwr1843boost-radar-review
Public review and experiment project for TI IWR1843BOOST mmWave radar application development.

## Goals

- Test IWR1843BOOST point cloud output
- Explore cfg tuning methods
- Build Python tools for TLV parsing and point-cloud analysis
- Provide C algorithm modules for filtering, clustering and tracking experiments
- Provide firmware overlay examples without redistributing the full TI mmWave SDK
- Allow public users to submit Pull Requests

## Important Notice

This repository does not redistribute the full TI mmWave SDK, TI Radar Toolbox, or TI prebuilt libraries.

Users should download TI software from the official TI website and follow TI license terms.
