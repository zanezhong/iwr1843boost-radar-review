# Setup Guide

This document records the basic setup steps for the IWR1843BOOST radar review project.

## Hardware

- TI IWR1843BOOST
- USB cable
- PC with Windows
- Optional: DCA1000EVM

## Software

- Code Composer Studio
- TI mmWave SDK
- Python 3.11
- Git
- VS Code

## Current Stage

This repository is currently in the initial setup stage.
